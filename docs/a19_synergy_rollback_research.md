# Shared synergy lists in AI checkpoints

The support-precision strength screen exposed another rollback reference mismatch. The incomplete run is preserved in the [strategy research log](ranked_replay_strategy_research.md#experiment-27-interruption-an-incomplete-correctness-failure-not-a-strength-result); its 293 complete records provide no admitted strength result.

The failing game is uniform mixed, pair 453, seed 102620692, Normal, green, compact opponent. Stock R2, the experimental support-R8 policy and its discarded-computation control all reproduce the failure on the opposing Arachna Queen's searched ordinal 26 in lap three. No precision refinement runs on that root. Before and after search, serialized board values match, but three shared-reference edges change.

`UnitsHolder.adjustBaseStats` assigns the same synergy string array to multiple units and their fight state. An incremental checkpoint cloned a touched owner's field bag while leaving untouched owners on the original array. The full-snapshot implementation captures all owners with one memo and already preserves these relationships. The previous aura repair covers a different set of shared owners and remains intact.

The repair in [battle_snapshot.ts](../src/simulation/battle_snapshot.ts) records the small synergy lists at checkpoint creation, keeps their original objects in captured field bags, and restores changed contents in place before restoring those bags. It reads the original field references directly so mutable-property getters do not accidentally capture whole units. Untouched unit bags remain uncopied. Equal independent lists stay independent, sparse holes survive, and unchanged frozen lists require no write. No native policy, value model, action catalog, creature rule or synergy effect changes.

Eight tests in [battle_snapshot_synergies.test.ts](../test/simulation/battle_snapshot_synergies.test.ts) cover unit-only and fight-only mutations, both first-touch orders, mutations through a retained live array, independent/equal/empty lists, sparse lists, immutable lists and reusable full snapshots. Seven fail on the old checkpoint code; the full-snapshot control passes. All eight pass with the repair, together with the existing snapshot and aura tests: **22 focused tests**. The complete isolated common build passes **7,206 tests**, TypeScript and generated/JSON copy steps. Targeted ESLint also passes.
