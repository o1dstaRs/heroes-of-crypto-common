# Map-visible contextual draft timing

`map-visible-contextual-override-v1` is a separate inactive timing hypothesis. It retains the exact
locked V3 draft, adopted contextual weights and revealed-ranged delivery policy. Only the extra
contextual override is deferred while the native public scouting view has no map. Its allowance
remains available for a later native decision after map reveal. V3 and delivery retain their own
independent consumed budgets, including decisions that the contextual head later reverses.

This tests the opportunity cost of saving an override for better information. It does not assume
that a later choice is better: an early bundle or creature can be worth more. All synergy variants
are already public before the first bundle. The candidate never reads the hidden map from a seed,
full pick state or concealed opponent. The five-point doctrine receives its map at the first bundle
and must keep exactly the current draft. Other doctrines receive it at the first level-three phase.
The native visibility provider supplies both conditions.

The references are current v13 and a matched draft with only its extra contextual head disabled.
Both retain V3, delivery and the same authoritative v13 setup/combat. Only the named entrant changes;
the opponent keeps current v13 throughout. Native offers, hidden collisions, revealed picks, tier-two
artifacts and budget consumption continue normally. No model is fitted or refitted, and the original
contextual study's failed safety gate and closed confirmation bank remain unchanged.
