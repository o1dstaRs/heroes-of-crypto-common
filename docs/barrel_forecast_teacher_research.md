# Observed A19 barrel choices and closed predictor development

The earlier paired forecast failed fresh strength confirmation. This follow-up asks what the unchanged
A19 policy actually does at the same eligible barrel boundary, retaining all cases instead of choosing
old losses or favorable opponents. The [complete evidence](evidence/barrel_forecast_teacher_development_20261118.json)
preserves registrations, source, validated data inventories, fixed folds, the inactive model and every
failed gate. It adds no serving policy or independent strength sample.

## Complete unchanged-policy acquisition

All **3,024 already opened v10 stock games / 756 families** reproduce their original full inputs,
action/event traces and outcomes. The observer always returns the original cleanup array, consumes
no extra RNG and adds no search rollout. It records only public combat state and joins observations to
the actual committed choice. Collection takes 5,482.367 seconds with eight nice-19 CPU actors.

Independent Python and Bun verification checks all **4,220 observations**, their public actor/action
joins, exact producer payload hashes and source/input/outcome controls. The fixed sixteen-case
preflight repeats in fresh collection processes: all **24 repeated observations** match exactly.
There are 679 families with an eligible observation; the other 77 families remain in the complete
original-control ledger. Outcomes are integrity controls, not training labels.

| Actual choice category        | Observations | Share |
| ----------------------------- | -----------: | ----: |
| Exact native barrel cleanup   |        1,313 | 31.1% |
| Exact proposal before cleanup |        1,042 | 24.7% |
| Another committed action      |        1,865 | 44.2% |

The descriptive third-action audit retains 873 moves, 510 waits, 232 defends, 236 spells, thirteen other
obstacle hits and one move-plus-melee attack. Nine moves become identical to the earlier proposal after
normalizing footprint order and absent false hazard flags. Of the remaining movement comparisons,
399 have a different final footprint from the earlier move. A matching endpoint alone does not prove
matching paths, hazards or actions. Independent Bun reconstruction matches every taxonomy count.

These opened-data diagnostics suggest a limitation of the two-proposal forecast: changing a weight
between cleanup and the earlier proposal cannot represent many of A19's observed alternatives. They
do not show that any particular alternative causes a battle win, or prove the cause of the failed
mixture's score. A future action model must verify legality and hypothetical-state behavior separately.

## Fixed family-disjoint development fit

Before collection completes, freeze a 110-feature public-input allowlist, family split, four L2 recipes,
training rule and confidence gate. Seeds, UUIDs, outcomes, chosen actions, labels and case identities
never enter the predictor. IDs only join the actor/initiative queue; 64 metamorphic checks change labels,
case metadata and UUIDs without changing features. The whole four-case family stays in one fold.

Train on 2,504 observations / 400 families; select regularization on 911 / 142; refit those two folds
once. Write the final artifact **before opening** the test file, which contains 805 / 137. The frozen
three-class linear softmax uses float64, 400 Adam steps and four predeclared L2 values. Validation
selects L2 = 0.1. CPU fitting and the fixed bootstrap take 2.078 seconds; this is not combat latency.

The untouched internal test has log loss **1.011871**, versus **1.075731** for the constant training-class
prior: a reduction of 0.063860, whole-family bootstrap 95% **0.040793 to 0.086569**. Accuracy is 47.95%.
Independent Bun inference reproduces every test probability within 4.45e-16, all folds, confusion
counts and losses. The frozen NumPy bootstrap supplies the reported interval; the Bun check verifies
predictions and aggregates, not a separate bootstrap RNG implementation.

The proposed override requires P(before) ≥ 0.85. **Zero test observations meet that threshold.** Support
and precision gates therefore fail; zero false rejections do not establish a safe classifier. The
model remains an inactive development artifact, raw SHA-256
`a59b6d8d58e6c139befba425885092e19f15d116ad3b2a2387f76dcd3e5f9e77`.
No threshold, feature, recipe or test partition is retuned to create activity after this result.

No candidate fight or cost bank opens. Better teacher-choice loss is not a strength gain or evidence
that the model generalizes to hypothetical rollouts. Further work needs a distinct action/legality
representation, unchanged native/controller memory semantics, new independent evidence against the
then-current v12 default, and the user's overall-average +10% compute check. Preserve both the original
forecast failures and this failed confidence gate.
