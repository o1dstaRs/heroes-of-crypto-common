description construction inside simulated stat refreshes. The complete profiled
outcome exactly matches its original control. This is a performance diagnosis,
not a new tactical policy or strength result.

previous output and every formula input. Reuse requires exact text and matching
minimum damage, percentage and per-stack constant. Changed text, powers, hydration
or rollback invalidates it through current values. Custom getters retain the
original path; no unit fields, combat rules, random draws or target memory change.
Four functional controls / 26 assertions pass, including actual native snapshot
rollback and preservation of extended description-property suffixes.

complete outcomes. Independent reconstruction verifies both full paired outputs

3,147,866 cache hits. This is a small reused screen from five exposed families,
with eight scenarios containing Last Fuse. The four without it used **3.988678%
more CPU**; the Last Fuse subgroup used 11.553212% less. Preserve every case.
These descriptive subgroups are not separate +10% gates or production estimates.
